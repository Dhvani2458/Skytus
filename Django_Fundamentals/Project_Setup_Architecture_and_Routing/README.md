# Task 1: Django Fundamentals and Setup

## Overview
This task covers the fundamentals of setting up a Django project, registering applications, configuring URL routing, and managing development environment settings.

## Topics Covered
- **Project Initialization:** Created a Django project and application.
- **App Registration:** Registered the application in `INSTALLED_APPS`.
- **Dynamic URL Routing:** Configured URL patterns to connect requests with appropriate views.
- **Environment Configuration:** Configured `DEBUG` and `ALLOWED_HOSTS` settings.

## Technologies Used
- Python
- Django
- SQLite
- VS Code

## How to Run
```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

## Learning Outcome
Gained practical experience in Django project setup, application configuration, URL routing, and basic environment settings.
