# Amazon-Inspired E-Commerce Landing Page

## 🌐 Live Demo

**Visit the website:** https://cloning-ecommerce-page.vercel.app/

## 📌 Project Overview

This project is a responsive, UI-only e-commerce landing page developed using ReactJS for **Assessment 2: Clone a Landing Page (Amazon / Flipkart UI)**.

The website features an Amazon-inspired shopping interface with product search, category filters, a promotional banner, product cards, and a demo shopping cart.

This project is developed for educational purposes and does not include backend services, authentication, or payment integration.

## ✨ Features

- Amazon-inspired header and navigation bar
- Custom ShopZone logo
- Product search functionality
- Promotional banner with a shopping call-to-action
- Product category filters
- Eight sample products displayed dynamically
- Product images, prices, ratings, and discount labels
- Add to Cart buttons with a demo cart counter
- Responsive design for desktop, tablet, and mobile
- Footer with informational links

## 🛠️ Technologies Used

- **Frontend:** ReactJS
- **Programming Language:** JavaScript (ES6+)
- **Styling:** CSS3
- **Build Tool:** Vite
- **Version Control:** Git and GitHub
- **Deployment:** Vercel

## ⚛️ React Concepts Implemented

- Functional components
- Props for passing product data
- State management using `useState`
- Dynamic list rendering using `map()`
- Product search and filtering using `filter()`
- Event handling for search, category selection, and cart interactions
- Reusable product card components

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Navigate to the project folder

```bash
cd ecommerce-landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal, usually `http://localhost:5173/`.
