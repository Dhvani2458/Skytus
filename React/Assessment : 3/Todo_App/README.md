# TaskFlow – React Todo App

A modern and responsive Todo application built using React and Vite. TaskFlow helps users organize daily tasks with an attractive interface, task tracking, and Light/Dark mode.

## 🚀 Live Demo

[**View TaskFlow – Todo App**](https://todoapp-ten-sandy.vercel.app/)

## ✨ Features

- **Add Tasks:** Create new tasks easily.
- **Edit Tasks:** Update existing tasks.
- **Delete Tasks:** Remove unwanted tasks.
- **Mark as Completed:** Mark tasks as completed or pending.
- **Task Filters:** View All, Pending, or Completed tasks.
- **Progress Tracking:** Track completed tasks with a progress bar.
- **Light/Dark Mode:** Switch between light and dark themes.
- **Local Storage:** Automatically save tasks and theme preferences.
- **Error Handling:** Prevent empty task submissions and display error messages.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Clear Completed:** Remove all completed tasks at once.

## 💾 Data Persistence

TaskFlow uses the browser's Local Storage API to save tasks and theme preferences.

- Tasks remain saved after refreshing the page.
- Theme preference is remembered.
- No backend or database is required.
